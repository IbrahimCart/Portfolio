## Autonomus Drone: 

Developed as part of a collaborative software engineering project, this Java-based application simulates and monitors autonomous drones in real time. The system generates drone telemetry, tracks information such as location, altitude, speed, heading, and battery level, and detects unusual behavior, including sudden GPS changes, unsafe movements, and low battery levels.

The project also includes a monitoring dashboard with drone position visualization, anomaly logging, and database integration for storing and retrieving detected issues. I contributed to anomaly detection, dashboard functionality, unit testing, debugging, and code documentation. Throughout development, our team used Git and GitHub for version control, Maven for project management, and JUnit for testing and reliability.


## Discord Music Bot:

- A small Discord bot that plays music in a voice channel, built with Python, discord.py and yt-dlp.

Slash commands: /play, /skip, /pause, /resume, /queue and /stop
Search by name or link: finds songs on YouTube first, falls back to SoundCloud, and accepts YouTube and SoundCloud links directly
Spotify support: paste a track, album or playlist link and the bot finds each song on YouTube or SoundCloud
Smarter results: prefers audio uploads over music videos, skips DRM-protected or unavailable results, and avoids remixes and reuploads unless you ask for them
Fast queueing: looks up the next song while the current one plays
Runs on macOS and Windows: setup steps for both are in this README

For private use in your own server.
